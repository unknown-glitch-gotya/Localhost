# Educational Data Mining System

An interactive Streamlit application implementing various Data Mining algorithms on student and educational datasets.

## Algorithms & Features Included
- **Classification:** Decision Tree (ID3, J48), Naïve Bayes, k-Nearest Neighbors (KNN)
- **Association Rule Mining:** Apriori Algorithm
- **Clustering:** K-Means
- **Domain-Specific Mining:**
  - Text Mining
  - Multimedia Mining
  - Spatial Data Mining
  - Web Usage Mining

## Setup & Running Locally

1. **Clone the repository:**
   ```bash
   git clone <repo-url>
   cd <repo-folder>
   ```

2. **Install requirements:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Streamlit app:**
   ```bash
   streamlit run app.py
   ```
